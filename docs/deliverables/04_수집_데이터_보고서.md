## 2. 수집 방법

1. 초기(9/7~9/30): 포털의 "상황 선택하여 찾기" 마법사를 브라우저로 순회하며 수동 수집 (기본 과실비율만, 13건)
2. 10/1: 도표 상세 페이지가 chartNo로 직접 접근 가능하고 가감요소·법규·판례까지 포함함을 확인해 **스크립트 수집으로 전환**
3. `차1-1` ~ `차70-12` 범위를 순차 요청 (요청 간 0.3초 지연). 존재하지 않는 번호는 HTTP 500을 반환하므로 연속 2회 실패 시 해당 그룹 종료
4. HTML을 파싱해 구조화 JSON으로 저장 ([05 저장소 설계](05_데이터_저장소_설계.md), [06 전처리 결과서](06_데이터_전처리_결과서.md))

기술 메모: 이 서버는 중간 인증서 체인이 불완전해 Python 기본 SSL 검증이 실패한다. SSL 검증을 끄지 않고 OS 인증서 저장소를 사용하는 `curl`로 수신한다.
