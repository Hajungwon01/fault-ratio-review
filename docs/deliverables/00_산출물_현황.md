## 해당 없음 처리 (확정)

ML/DL 학습결과서, 학습한 ML/DL 모델, 자체 sLLM은 본 프로젝트가 모델을 학습하지 않고 외부 LLM API(프롬프트 + 도구 호출)를 쓰므로 해당 없음으로 처리한다. 발표·보고 시 "학습 대신 기준표 구조화 + 프롬프트 설계 + 에이전트 검증 구조로 성능을 확보했다"는 점을 [02 기획서 §8](02_프로젝트_기획서.md), [07 아키텍처](07_AI_시스템_아키텍처.md)로 설명한다.

## 확인이 필요한 항목

1. 벡터DB/GraphDB: 도표 108개 규모라 필수는 아니나 산출물 항목이라, 임베딩 검색을 도입해 기존 키워드 매칭과 비교하는 실험으로 채울지.
2. 각 산출물의 제출 형식(docx/hwp/pdf 등). (중간 발표는 없음 — 2026-10-27 확인)
