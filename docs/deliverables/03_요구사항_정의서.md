## 2. 비기능 요구사항

| ID | 요구사항 | 상태 | 비고 |
|---|---|---|---|
| NFR-01 | API 키 없이도 전체 파이프라인이 mock 모드로 끝까지 실행된다 | ✅ | 테스트로 검증 |
| NFR-02 | A/B 에이전트는 병렬 실행되어야 한다 | ✅ | async 클라이언트로 수정 |
| NFR-03 | 모든 판단은 기준표 도표번호·법조항과 연결되어 설명 가능해야 한다 | 🔄 | 인용 검증 구조는 구현, 품질은 평가 예정 |
| NFR-04 | 목록에 없는 도표·조문 인용(환각)이 평가 시나리오에서 0건이어야 한다 | ⬜ | S1-2 완료 조건 |

| NFR-07 | 응답 시간·비용 목표 | ⬜ | 실측 1건: 요청당 40~80초 (gpt-4o-mini, 에이전트 7개·도구 루프). 비용 미측정. 목표 설정 필요 |
| NFR-08 | 자동 테스트로 핵심 로직을 검증한다 | 🔄 | pytest 125개 (conftest 로 .env 격리 — 테스트는 실제 API를 호출하지 않음) (실제 모델 테스트는 RUN_KURE=1 로 선택 실행) |
| NFR-09 | 평가 시 포털식 단순 매칭(baseline: 도표 하나 + 기본 과실비율)과 본 파이프라인을 같은 시나리오로 비교해 차이를 수치로 제시한다 | ⬜ | #18 |

## 3. 제약 사항

- 범위는 텍스트 기반 사고 정황 입력 (이미지는 Stretch)
- 기준표는 "차 대 차" 도표 한정 (보행자·자전거 제외)
- 기준표 데이터는 출처(손해보험협회 과실비율정보포털)를 표기하고 공개 재배포하지 않는다. 데이터 공개 배포·상용화 시에는 이용조건을 확인한다 (#23)
- 본 시스템의 결과는 심사 보조용이며 법적 효력이 없다
